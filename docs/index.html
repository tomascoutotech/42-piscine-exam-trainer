Como funciona o exame

O exame sorteia um exercicio de cada nivel, a comecar no nivel 0. So passas ao nivel seguinte depois de validar o anterior — nao se salta. Cada exame vai ate a um nivel diferente: o exam00 para no 1, o final vai ate ao 5.

A correccao nao corre a norminette. Corre tres coisas:

cc -Wall -Wextra -Werror   compila sem um unico aviso
nm                         nenhuma funcao alem das permitidas
diff                       o output igual byte a byte

E por isso que a newline a mais no fim chumba um exercicio inteiro. Corre sempre | cat -e: o $ mostra-te onde a linha acaba de verdade.

Isto aqui no browser nao compila nada

Esta pagina mostra-te o enunciado, os testes e a resolucao. Quem compila e corrige a serio e o simulador de linha de comandos que esta no repositorio:

git clone https://github.com/tomascoutotech/42-piscine-exam-trainer
cd 42-piscine-exam-trainer
./exam start final

Precisa de Linux, macOS ou WSL — o mesmo que vais ter no exame.
